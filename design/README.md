# CliffSense — iOS Prototype

`ios-prototype.html` is a self-contained, clickable iOS-style prototype of the
CliffSense (MyBenefitsPA) mobile experience. Open it in any browser — no build
step or dependencies (all CSS/JS/SVG is inline).

## What's in it

- **Benefits dashboard** with Apple Wallet–style program cards, split into two
  families:
  - **Federal (SSA)** — deep navy cards with the Social Security seal + US flag.
  - **State (Pennsylvania)** — light Commonwealth cards with the red PA keystone.
- **Program detail pages** with a matching hero card, a live **"What if…"
  simulator** (drag to project income/resources against a limit), stats, and
  counted-activity list.
- **Beneficiary switcher** (family account managing multiple people; one
  beneficiary shows an over-limit / breach state).
- **Calendar** page (month grid + reporting deadlines) and **event detail**
  pages in the Apple Wallet event layout.
- **Alerts**, **Advisor** (chat), **Documents**, and **Settings** tabs.
- Working **connect-bank** flow, quick-action sheets, toasts, and a
  **dark mode** toggle (Settings → Dark appearance).

## Notes

This is a design prototype for review only — state is in-memory and resets on
reload, and the seals/marks are stylized (not official government artwork).
